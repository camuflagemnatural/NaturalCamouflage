# nc-admin
Painel da loja Natural Camouflage. Publicar como repositório `nc-admin` no mesmo GitHub Pages das outras páginas (acesso em `/nc-admin/`).
Depende de `/nc-core/css/core.css` e da API `/api/admin` do backend. Não usa `core.js`, então a sessão da equipe é separada da sessão do cliente.
Login: o e-mail e a senha definidos em `ADMIN_EMAIL` / `ADMIN_PASSWORD` no Render (ou criados com `npm run create-admin`).
